# 🎮 Alpha Clash Pro

Alpha Clash Pro is a fun and interactive keyboard typing game built with **HTML, CSS, and JavaScript**.

In this game, a random alphabet appears on the screen, and the player has to press the corresponding key on the keyboard. The game keeps track of the player's **score and remaining lives**, making it a simple and engaging way to practice keyboard typing and JavaScript DOM manipulation.

## ✨ Features

- 🎯 Random alphabet appears on the screen
- ⌨️ Keyboard-based gameplay
- ❤️ Life counter
- 🏆 Score counter
- ⚡ Real-time keyboard input detection
- 🎮 Start/Play functionality
- 🔄 New alphabet generated after every correct input
- ❌ Life decreases when the wrong key is pressed
- 📱 Simple and responsive game interface
- 🎨 Interactive UI with custom CSS styling

## 🛠️ Technologies Used

This project was built using:

- **HTML5** — For creating the game structure
- **CSS3** — For styling and designing the game interface
- **JavaScript (ES6)** — For game logic, keyboard events, score/life management, and DOM manipulation
